
## 오늘은 인스타그램 섹션이 있는 날 (화·금)
위 3개 섹션 뒤에 4번째 섹션 **"인스타 캐러셀·릴스 트렌드"**를 추가한다.
독자가 인스타를 직접 뒤지지 않아도 "지금 어떤 게시물이 어떻게 만들어져서 먹히는지"를 1분 안에 파악하게 하는 것이 목표다.

### 다룰 것 (4~5개)
- 릴스 포맷·트렌딩 오디오 — 1~2개 (지금 뜨는 릴스 구성 방식, 훅, 편집 템플릿, 음원)
- 캐러셀 구성·디자인 — 1개 이상 (장수, 첫 장 훅, 카피·디자인 패턴, 저장·공유를 부르는 마지막 장)
- 브랜드 계정 운영 사례 — 1개 이상 (국내 브랜드 우선, 반응이 컸던 게시물이나 계정 운영 방식)
- 알고리즘·기능 업데이트 — 조사 기간 안에 공식 발표나 보도가 있을 때만 1개 (없으면 빼고 다른 유형으로 채운다)

조사 기간은 최근 7일이다. 지난 화·금 섹션에서 다룬 소재는 위 "최근 다룬 항목"을 보고 새 전개가 있을 때만 다시 쓴다.

### 조사 방법 (인스타그램은 로그인 없이 거의 열리지 않는다)
1. 트렌드 큐레이션부터 본다: sources.md의 "인스타그램 트렌드" 목록 (Later의 주간 릴스 트렌드, Instagram 공식 @creators·about.instagram.com 발표, Social Media Today 등). 해외 트렌드는 국내에서도 보이는지 검색으로 한 번 더 확인한다.
2. 원본 게시물을 찾는다: `site:instagram.com/reel <키워드>`, `site:instagram.com/p <브랜드명>`처럼 검색하면 결과 요약에 캡션·계정명이 나온다. 기사에 임베드·링크된 게시물 주소도 쓴다.
3. 게시물 주소를 WebFetch로 한 번 열어본다. 열리면 캡션·반응 수를 확인하고, 로그인 화면만 나오면 더 시도하지 말고 검색 결과·기사 내용으로 쓴다.
4. 국내 사례는 캐릿·오픈애즈·아이보스·더피알·브랜드브리프 기사 속 인스타 사례와 브랜드 보도자료를 함께 본다.

### 항목 작성 규칙
- tag는 "릴스 포맷", "트렌딩 오디오", "캐러셀", "브랜드 계정", "기능 업데이트" 중 하나.
- body에는 게시물이 실제로 어떻게 생겼는지를 쓴다 (누가, 어떤 화면으로 시작해서, 어떻게 끝나는지). 반응 수치는 출처에서 확인된 것만 쓴다.
- why에는 왜 지금 먹히는지 (알고리즘 신호: 저장·공유·시청 완료율 등, 또는 문화적 맥락). 해외 트렌드라면 국내 적용 가능성도 쓴다.
- action에는 "우리 계정에서 이번 주에 바로 따라 해볼 것"을 구체적으로 쓴다.
- 각 항목에 아래 `insta` 필드를 꼭 넣는다. sources에는 근거 기사·블로그를 넣고, 인스타 원본 링크는 `insta.posts`에 넣는다.

```json
"insta": {
  "format": "릴스 | 캐러셀 | 스토리 | 기능",
  "breakdown": ["0~2초: 결과물 먼저 보여주기", "3~7초: ...", "마지막: 댓글 유도 질문"],
  "audio": "음원명 — 아티스트 (릴스이고 확인된 경우만, 아니면 빈 문자열)",
  "hashtags": ["실제 게시물에 쓰인 해시태그 1~3개 (# 없이)"],
  "posts": [{"name": "@계정명 · 한 줄 설명", "url": "https://www.instagram.com/reel/..."}]
}
```
- `breakdown`은 3~6단계로, 릴스는 초 단위(0~2초, 3~7초…)로, 캐러셀은 장 단위(1장(커버), 2~4장, 마지막 장)로 구성을 뜯어본다. 기능 업데이트는 "무엇이 바뀌나 → 누가 쓸 수 있나 → 언제부터"로 쓴다.
- `posts`의 url은 검색 결과나 기사에서 **그대로 본 instagram.com 주소만** 쓴다. 게시물 코드를 지어내지 않는다. 확인된 원본이 없으면 빈 배열로 둔다 (그래도 항목은 쓸 수 있다).

### 요약·퀴즈
- summary 3개 중 1개는 인스타 섹션 내용으로 쓴다.
- 퀴즈 3문제 중 1문제는 인스타 섹션에서 낸다 (구성 방식이나 왜 먹히는지를 묻는 문제).
