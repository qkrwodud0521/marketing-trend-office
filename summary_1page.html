프로젝트 목적: 마케팅 준비생 및 실무자가 매일 쏟아지는 최신 트렌드를 빠르게 파악할 수 있도록, Claude AI가 웹을 자동 조사·검증하여 주기별 리포트를 발행합니다. 팀원은 픽셀아트 오피스(office.html)에서 가상 팀원들과 상호작용하며 퀴즈, 스크랩, 아이디어 메모를 통해 마케팅 인사이트를 체득합니다.

마케팅팀 오피스(office.html) 주요 인터랙션 기능
출근·보고 & 승진 시스템
  • 스케줄별 출근: 가상 팀원이 정해진 시간에 출근해 책상으로 찾아와 리포트 보고 (미열람 시 야근).
  • 레벨업 & 오피스 인테리어: 완독 시 XP를 획득하여 인턴 → 사원 → … → CMO(Lv.10)로 승진.
  • 승진 단계마다 화분, 커피머신, 소파, 네온사인, 고양이 등 오피스 오브젝트 순차 해금.
확인 퀴즈 & 오답노트
  • 학습 점검 퀴즈: 리포트 완독 후 담당 팀원이 3문항 출제 (정답 및 만점 보너스 XP 지급).
  • 오답노트 복습: 틀린 문제는 오답노트에 보관되며, 다음 날 하루 사원과 복습 후 재해결(+3 XP).
  • 주간 복습 탭: 매주 금요일 주디 대리의 안내로 한 주간 데일리 퀴즈 10문항 종합 풀이.
3단계 아이디어 스크랩북
  • 실전형 메모 템플릿: 스크랩 카드별 1. 관찰 → 2. 인사이트 → 3. 실무적용 3단계 구조화 메모 (완성 시 +5 XP).
  • 희망 브랜드 맞춤 적용: 관심 기업(예: 올리브영) 설정 시 적용 질문이 브랜드 맞춤형으로 전환.
  • 포트폴리오 연계: 스크랩된 카드를 마크다운으로 원클릭 복사하여 면접/자소서에 즉시 활용.
리더보드 & 커리어 연계
  • 실시간 랭킹 & 배지: 팀원 간 경험치 순위표(시상대), 14종의 성장 업적 배지 게시판 전시.
  • 채용 공고 & 승진 쿠폰: 메인 화면 실시간 마케팅 채용공고 연동 및 특정 직급 달성 시 혜택 지급.
  • 마일스톤 추천: 스크랩/아이디어 달성도에 따라 실전 챌린지 및 가이드북 안내.
시스템 아키텍처 & 운영 가이드
자동화 파이프라인 (Catch-up)
  • 무중단 캐치업: 맥이 꺼져 있어도 켜지는 즉시 5분 주기로 누락된 리포트(최근 3일) 자동 감지·발행.
  • 데이터 검증: Claude CLI 헤드리스 실행 후 JSON 스키마·출처 URL을 자동 검증하여 오류 방지.
  • macOS 네이티브 알림: 신규 리포트 발행 완료 시 맥 시스템 알림 즉시 발송.
모바일 지원 & 빠른 실행
  • GitHub Pages & 멀티 기기: 발행 시 자동 push되어 모바일 웹/PWA로 열람 및 구글 시트 데이터 백업.
  • 스케줄 등록: ./scripts/schedule.sh install
  • 수동 직접 실행: python3 scripts/run.py daily (특정일 지정 가능)
